# 接口预留与共同契约清单

当前状态：F01—F08 已完成；共享查询、校验、发布事件和审计接口已实现，F09—F16 的业务路由仍由同学实现。联调入口见 [F09—F16 联调与共享能力](../f09-f16-integration.md)，完整端点字段见 [接口契约审查稿](api-contract.md)。

| 公共能力 | 本方提供 | 同学用途 |
|---|---|---|
| 人员与资格查询 | 已实现员工状态、技能、可用时间 | 请假影响分析、换班候选判断 |
| 时间与偏好写入 | 已实现结构化校验、本人权限检查 | AI 解析经用户确认后的保存 |
| 外部不可用信息接入 | 将额外不可用区间纳入统一校验的适配契约 | 已批准请假接入 |
| 基础约束模型 | 技能、覆盖、时间、工时及跨周规则 | 动态调班复用硬约束 |
| 当前班表与版本查询 | 已实现周期、当前版本、员工安排和版本快照 | 申请选班、方案基准与差异 |
| 统一变更校验 | 已实现冲突列表、规则定位、版本检查 | 换班与候选方案最终检查 |
| 发布服务 | 已实现幂等、事务、版本生成、并发冲突处理 | 换班及调班应用结果 |
| 发布事件与审计事实 | 已实现 outbox 与审计增量查询 | 通知、日志查询与确认流程 |
| 排班结果指标 | 已实现必要工时、班次数、偏好满足及变更指标 | AI 解释、统计展示与导出 |

后续每份契约必须包含：输入输出、示例、权限、状态前置条件、错误、幂等、并发控制、事务归属以及实现状态。

请假批准与发布需要共同的并发控制规则；换班审批与新版本发布需明确原子提交边界。接口约定不能只定义正常响应而忽略这些条件。

本方不创建能假装完成请假、换班、动态调班或 AI 调用的接口。未实现能力在文档中标识；开发测试样例须与正式业务路径分开。
